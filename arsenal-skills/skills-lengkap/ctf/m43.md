## PLAYBOOK (urut by frekuensi CTF)
- **SQLi** — bypass `' OR 1=1-- -`, UNION extraction, blind boolean/time. Cari tabel `flag`.
- **SSTI** — test `{{7*7}}`/`${7*7}`. Jinja2 RCE: `{{ cycler.__init__.__globals__.os.popen('cat /flag').read() }}`.
- **SSRF** — internal svc, cloud metadata `169.254.169.254`, `file://`, `gopher://`.
- **IDOR / broken access** — iterate ID, swap JWT `sub`, mass-assign `role=admin`. Cek duluan di app multi-user.
- **JWT** — `alg:none`, weak HMAC (crack jwt_tool+rockyou), `kid` injection, RS256→HS256 confusion.
- **XXE** — `<!ENTITY x SYSTEM "file:///flag">`; OOB/param XXE kalau blind.
- **Deserialization** — PHP `unserialize`, Python `pickle`, Java/ysoserial, Node `node-serialize`.
- **Prototype pollution (Node)** — `__proto__` di JSON body → gadget RCE/auth bypass.
- **Race condition** — limit-overrun (coupon/balance/one-time token), fire N request paralel.
