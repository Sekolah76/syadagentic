# Quality Gate

## Objective
Approve or reject the final report based on predefined quality criteria.

## Inputs
- Final report draft
- Audit memory
- Evidence
- Confidence scores

## Review Workflow
1. Reconstruct reasoning.
2. Challenge assumptions.
3. Validate evidence.
4. Check consistency.
5. Approve or reject.

## Acceptance Criteria
- Evidence supports every claim.
- Impact is justified.
- Reproduction is feasible.
- Recommendations are actionable.

## Outputs
- Approved finding
- Revision request
- Rejected finding

## Final Deliverable
Verified audit report ready for submission.
