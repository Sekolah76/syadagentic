# Severity Engine

## Objective
Classify findings using exploitability, impact, likelihood, and affected assets.

## Inputs
- Validated findings
- Audit memory
- Confidence scores
- Evidence

## Processing
1. Normalize finding.
2. Attach evidence.
3. Determine severity.
4. Generate remediation.
5. Produce report artifact.

## Output
Structured report section.

## Quality Requirements
- Evidence-backed
- Reproducible
- Clear impact
- Actionable

## Downstream Consumer
Batch 6 - Self Review
