# Domain lenses

## Web2

Focus on auth/recovery, sessions, tenant boundaries, object authorization, upload/parser chains, SSRF destinations, internal APIs, caches/proxies, queues, cloud IAM, and admin tooling.

## Smart contracts / DeFi

Focus on authority, token movement, accounting invariants, callbacks, arbitrary calls, oracle freshness/manipulation, liquidation, rounding, share conversion, governance, upgradeability, signature domains, and temporary liquidity.

## Bridges

Map source finality, proof verification, message uniqueness, replay protection, validator/guardian thresholds, relayer assumptions, mint/unlock symmetry, and emergency controls.

## Validators / distributed systems

Map untrusted messages, event ordering, epoch/round transitions, persistence, replay, restart, snapshots, quorum calculations, fork choice, equivocation handling, resource bounds, and deterministic execution.
