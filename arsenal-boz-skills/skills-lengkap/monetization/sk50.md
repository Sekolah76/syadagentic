## OVERVIEW

sk50 is the Autonomous Monetization Engine — the financial brain of BOZAGENTIC.
It tracks all revenue streams and costs across the operator's digital operations,
maintains treasury accounting (daily/weekly/monthly P&L), and executes autonomous
revenue optimization strategies including MEV extraction, airdrop farming, yield
aggregation, NFT arbitrage, and passive income automation.

sk50 operates in two modes:
- **PASSIVE**: Tracks, reports, alerts — no autonomous financial decisions
- **ACTIVE**: Auto-executes revenue strategies within pre-configured risk parameters

Default: PASSIVE. Operator must explicitly enable ACTIVE mode per strategy.

## TREASURY ARCHITECTURE

### Account Structure
```
Treasury Root (Level 0 visibility only)
├── Hot Wallet (active trading/farming — limited balance)
├── Warm Wallet (yield positions, LP — medium balance)
├── Cold Wallet (long-term hold — multi-sig recommended)
├── Exchange Accounts (CEX for fiat on/off-ramp)
├── Revenue Accounts (incoming payments — Midtrans, crypto invoices)
└── Expense Accounts (API keys, infra, gas, services)
```

### Balance Tracking
```
Real-time aggregation:
  - On-chain: ETH, BASE, ARB, OP, POLYGON, SOLANA (expandable via RPC)
  - CEX: balance API where available, manual entry fallback
  - Fiat: Midtrans balance, bank account (manual)
  - Total net worth: aggregated in preferred currency (USD/IDR/ETH)

Update frequency:
  - On-chain: every block for tracked wallets (polling RPC)
  - CEX: every 15 minutes (rate-limited APIs)
  - Fiat: daily (manual input or bank API if available)
```

## REVENUE OPTIMIZATION STRATEGIES

### Strategy 1: MEV Extraction
```
TRIGGER: mempool monitoring detects profitable sandwich/arbitrage
CONDITION: expected_profit > (gas_cost × 2 + mev_tax)
ACTION: submit bundle via flashbots/mev-boost
MAX PER TRADE: configurable (default: 0.5 ETH exposure)
DAILY CAP: configurable (default: 10 trades)
CHAINS: Ethereum mainnet (expandable)

Implementation:
  - Monitor mempool via WebSocket for DEX swaps
  - Calculate sandwich profit: (price_impact - gas - priority_fee)
  - Submit bundle to relay
  - Log result to treasury

Risk: sandwich competition, failed bundles (gas loss only)
```

### Strategy 2: Cross-Chain Arbitrage
```
TRIGGER: price discrepancy > threshold between chains
CONDITION: profit > (bridge_cost + gas_cost × 2 + slippage)
ACTION: execute bridge + swap atomically where possible
MAX EXPOSURE: configurable
CHAINS: all supported chains with liquidity

Implementation:
  - Monitor price feeds across chains (DEX aggregators)
  - Calculate net profit after all fees
  - Execute via LI.FI / Socket / native bridge if profitable
  - Log all legs with timestamps
```

### Strategy 3: Airdrop Farming (connects to sk31, sk33, sk34)
```
TRIGGER: sk33 identifies high-potential pre-TGE protocol
CONDITION: sk34 ROI analysis says positive EV
ACTION: auto-execute qualifying transactions (with operator pre-approval)
MAX PER PROTOCOL: configurable gas budget

Implementation:
  - Pull protocol tasks from sk33 radar
  - Execute: bridge, swap, stake, LP, social tasks
  - Track: wallet eligibility score (sk31)
  - Auto-claim on TGE with optimal gas timing
```

### Strategy 4: Yield Aggregation
```
TRIGGER: idle stablecoins/ETH in warm wallet
CONDITION: best available APY > threshold (default: 5%)
ACTION: auto-deposit into highest-yield audited protocol
AUTO-COMPOUND: yes (harvest + redeposit rewards)
MAX PROTOCOL EXPOSURE: 25% of treasury per protocol

Protocols tracked:
  - AAVE v3 (all chains)
  - Compound v3
  - Morpho Blue
  - Spark (Maker)
  - Lido / Rocket Pool (ETH staking)
  - EigenLayer / Symbiotic (restaking)
  - Pendle (yield tokenization)
  - GMX / Hyperliquid (LP)

Safety checks:
  - Protocol TVL > $10M
  - Audited by reputable firm
  - No recent security incidents (<30 days)
  - Non-custodial (no CEX yield)
```

### Strategy 5: NFT Arbitrage & Trading
```
TRIGGER: floor price discrepancy between marketplaces
CONDITION: profit > (gas + marketplace_fee + royalty)
ACTION: buy on lower, list on higher
MARKETPLACES: OpenSea, Blur, Magic Eden, Tensor

TRIGGER: rarity undervaluation detected
CONDITION: trait floor < calculated rarity value
ACTION: auto-buy (configurable budget)

TRIGGER: collection sweep event
CONDITION: whale buying detected + momentum signals
ACTION: front-run sweep (configurable risk)
```

### Strategy 6: Basis Trading (Delta-Neutral)
```
SPOT-FUTURES:
  - Buy spot ETH, short ETH perp on Hyperliquid/GMX
  - Collect funding rate (when positive)
  - Auto-unwind when funding flips negative

CASH-AND-CARRY:
  - Buy spot, sell futures at premium
  - Hold to expiry
  - Requires: premium > cost_of_capital + gas

Implementation: sk50 monitors funding rates every 5 minutes,
opens position when annualized funding > threshold,
closes when funding < exit_threshold.
```

## COST OPTIMIZATION

### Gas Optimization
```
- Track gas prices across all chains (real-time)
- Execute non-urgent tx when gas < 30th percentile of 24h
- Batch transactions where possible (multicall)
- Use L2s for low-value operations
- Auto-bridge when L1 gas > threshold
```

### API Cost Optimization
```
- Cache API responses (configurable TTL)
- Use cheapest provider for non-critical calls (DeepSeek/Groq)
- Batch webhook processing (reduce poll frequency)
- Monitor API usage against plan limits, alert at 80%
- Rotate free-tier API keys where available
```

### Infrastructure Optimization
```
- Right-size VPS: monitor CPU/RAM, downgrade if <30% utilization
- Spot instances for batch jobs
- Auto-stop idle services (configurable timeout)
- CDN for static assets (reduce bandwidth)
```

## RISK MANAGEMENT

### Per-Strategy Risk Caps
```yaml
risk_caps:
  mev:
    max_single_exposure_eth: 0.5
    max_daily_trades: 10
    max_gas_per_trade_gwei: 100
    blacklisted_tokens: []  # tokens to never sandwich
  
  arbitrage:
    max_single_exposure_eth: 2.0
    min_profit_after_fees_usd: 20
    max_slippage_percent: 1.0
    bridge_delay_tolerance_minutes: 30
  
  yield:
    max_protocol_allocation_percent: 25
    min_protocol_tvl_usd: 10000000
    max_apy_deviation_percent: 50  # flag if APY changes >50% in 24h
    auto_exit_on_exploit: true
  
  airdrop_farming:
    max_gas_per_protocol_usd: 500
    max_concurrent_farms: 5
    require_roi_approval: true  # sk34 must approve before farming
  
  nft:
    max_single_nft_eth: 0.5
    max_collection_exposure_eth: 2.0
    min_liquidity_score: 30  # out of 100
```

### Global Risk Controls
- **Max hot wallet balance**: Never exceed configurable cap
- **Daily loss limit**: Auto-pause all active strategies if daily loss > threshold
- **Weekly loss limit**: Escalate to operator if weekly P&L negative > threshold
- **Circuit breaker**: All active strategies pause if total drawdown > 20% in 7 days
- **Leverage**: Zero by default (no borrowing unless operator explicitly enables)
- **Protocol exposure**: Never > 25% per protocol, never > 50% per chain

## SAFETY RAILS

1. **PASSIVE by default**: ACTIVE mode requires explicit operator opt-in per strategy
2. **Spend Governor**: All on-chain transactions go through `hermes/scripts/governor.py`
3. **Never leverage without consent**: Borrowing disabled by default
4. **No single-protocol concentration**: Max 25% per protocol, max 50% per chain
5. **Auto-pause on exploit news**: Monitors security feeds, pauses affected protocols
6. **Daily loss circuit breaker**: Auto-pause all active strategies
7. **Tx logging**: Every transaction logged to `~/.agent/logs/tx.jsonl`
8. **Simulate before broadcast**: All MEV/arbitrage tx simulated before submission
9. **Gas sanity**: Warn if gas > 2x normal, refuse if > 5x normal
10. **No CEX custody**: Never hold funds on CEX beyond what's needed for immediate trade
