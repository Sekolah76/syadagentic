# Capability Taxonomy

Use consistent capability labels to avoid false matches.

## Access
- NETWORK_REACH_PUBLIC
- NETWORK_REACH_INTERNAL
- AUTH_USER
- AUTH_TENANT_ADMIN
- AUTH_GLOBAL_ADMIN
- LOCAL_UNPRIVILEGED
- LOCAL_SERVICE_IDENTITY

## Read
- READ_PUBLIC_METADATA
- READ_CROSS_TENANT_OBJECT
- READ_SECRET_MATERIAL
- READ_SIGNING_KEY
- READ_PROTECTED_STATE

## Write
- WRITE_OWN_OBJECT
- WRITE_CROSS_TENANT_OBJECT
- WRITE_CONFIG
- WRITE_EXECUTABLE_PATH
- WRITE_PROTOCOL_STATE

## Execution
- EXEC_CLIENT_CONTEXT
- EXEC_SERVER_WORKER
- EXEC_SERVICE_IDENTITY
- EXEC_HOST_PRIVILEGED

## Identity/session
- ENUMERATE_ACCOUNT
- CREATE_OR_FIX_SESSION
- OBTAIN_ONE_TIME_TOKEN
- OBTAIN_REUSABLE_TOKEN
- IMPERSONATE_USER
- IMPERSONATE_SERVICE

## Web3/protocol
- INFLUENCE_ORACLE_INPUT
- INFLUENCE_TRANSACTION_ORDER
- ACQUIRE_TEMPORARY_LIQUIDITY
- ALTER_GOVERNANCE_WEIGHT
- SUBMIT_INVALID_STATE_CANDIDATE
- CAUSE_STATE_DIVERGENCE
- BYPASS_FINALITY_OR_VERIFICATION
- MOVE_OR_LOCK_ASSETS

Capabilities with different labels are not interchangeable without evidence.
