# Phase 7 — Exploit Construction & Validation

## Goal
Turn validated hypotheses into realistic exploit scenarios.

## Principles
- Do not invent attacker capabilities.
- Every exploit must map to a violated invariant.
- Every step must be supported by execution flow.
- Distinguish theoretical issues from practical exploits.

## Deliverables
- Exploit hypothesis
- Preconditions
- Attack path
- Impact assessment
- Confidence score
