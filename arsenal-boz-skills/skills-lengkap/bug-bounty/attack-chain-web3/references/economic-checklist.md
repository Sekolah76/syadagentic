# Web3 Economic Feasibility Checklist

- [ ] Required starting capital calculated
- [ ] Flash/borrow limits established
- [ ] Pool/order-book liquidity measured
- [ ] Slippage and fees included
- [ ] Gas/compute costs included
- [ ] Oracle update mechanics validated
- [ ] Arbitrage/liquidation response considered
- [ ] Protocol caps and rate limits included
- [ ] Net extractable value or griefing cost estimated
- [ ] Result is irreversible or recovery is explained
- [ ] TVL is not used as loss without an executable path
