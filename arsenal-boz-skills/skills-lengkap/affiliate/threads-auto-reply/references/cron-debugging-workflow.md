# Cron Job Debugging — Threads Reply & Post (verified 2026-06-18)

## Quick Diagnosis Flowchart

When cron shows `last_status: "error"`:

1. **Check output logs:**
   - `~/.hermes/cron/output/<job_id>/` — naming: `YYYY-MM-DD_HH-MM-SS.md`
   - Shows script exit code, timeout, and error message

2. **Check verbose logs:**
   - Reply: `/tmp/threads_reply.log` (log() function writes here, NOT stdout)
   - Post: `/tmp/threads_post.log`
   - Use `tail -20 /tmp/threads_reply.log` for recent activity

3. **Reproduce manually:**
   ```bash
   # Reply
   bash ~/.hermes/scripts/cron_reply.sh
   
   # Post
   cd ~/.hermes/scripts && python3 cron_post.py
   ```

## Common Errors

### `rewrite_error` in stdout
**Cause:** Playwright browser binary missing after pip upgrade
**Fix:** `python3 -m playwright install chromium` (~260MB download)
**Two signatures:**
- `Executable doesn't exist at .../chrome-headless-shell`
- `raise rewrite_error(error, f"{parsed_st['apiName']}: {error}")`

### `timeout after 300s`
**Cause:** Script hung (CDP port stuck, Chrome zombie, or excessive `time.sleep()`)
**Fix:**
```bash
lsof -i :9222  # Check if Chrome is stuck
pkill -9 -f "Google Chrome"  # Kill stale Chrome
```

**Common root cause: Excessive sleep in `threads_reply_v6.py`**
The reply script has ~80-100s of `time.sleep()` calls that push total runtime past 300s:
- Line 755: `sleep(randint(30,60))` — after successful reply (reduce to 5s)
- Lines 290, 481, 630: `sleep(10)` × 3 — page load waits (reduce to 3s)
- Lines 346, 510, 594: `sleep(8)` × 3 — navigation waits (reduce to 3s)
- Line 557: `sleep(8)` — Chrome launch (keep as-is)

**Quick fix:**
```bash
sed -i '' 's/time.sleep(10)/time.sleep(3)/g; s/time.sleep(8)/time.sleep(3)/g; s/time.sleep(random.randint(30, 60))/time.sleep(5)/g' ~/.hermes/scripts/threads_reply_v6.py
```

**After fix:** Total sleep drops from ~100s to ~25s, script finishes in ~150s (well within 300s timeout).

### `exit code 1` + product name
**Cause:** Post script failure (dedup rejection, cookie expired, or Threads UI changed)
**Fix:** Check verbose log for specific error

## Script Architecture

### Reply Script (`threads_reply_v6.py`)
- **Method:** CDP (Chrome DevTools Protocol) on port 9222
- **Logs:** `log()` → `/tmp/threads_reply.log`, `summary()` → stdout
- **Duration:** 3-5 minutes (keyword search + relevance filter + link dedup)
- **Progress:** Monitor via `tail -f /tmp/threads_reply.log`

### Post Script (`threads_post_v6.py`)
- **Method:** Playwright headless Chromium
- **Logs:** `log()` → `/tmp/threads_post.log`, `summary()` → stdout
- **Duration:** 1-2 minutes
- **Content:** Generated by `cron_post.py` (4-kategori rotation)

## Stagger Rule
Reply + Post must be ≥15min apart (Chrome port 9222 conflict).
