# Meta Spam Flag Pitfall (June 2026)

Meta aggressively flags accounts (e.g., `jagonya_shopee`) for spam if they drop direct affiliate URLs in high volume via replies.

**Rule:**
- Affiliate links should ONLY be placed in original thread posts (via `threads-auto-post`).
- Replies (`threads-auto-reply`) should NEVER contain direct URLs. They should focus purely on engagement, mentioning the product name, and directing users to check the profile or DM for links.
