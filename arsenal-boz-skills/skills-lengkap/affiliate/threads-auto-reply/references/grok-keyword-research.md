## Strategy

Focus on keywords containing request signals:
- **butuh** = need
- **tolong** = please help
- **saran** = advice
- **dong** = casual request particle
- **guys** = group address
- **plis** = please
- **rekomendasiin** = recommend (verb form)

These keywords filter out recommendation-giving posts and target people actively seeking help → higher conversion for affiliate links.
