# Shopee Anti-Scraping & WAF Bypass Evaluation
**Date:** 2026-06-26

## Core Findings
Shopee ID employs an aggressive Akamai Bot Manager implementation specifically tuned to block browser automation frameworks and headless HTTP clients from accessing critical data (like ratings/reviews) directly.

### 1. HTTP Clients (curl_cffi / Requests)
- **Product Page (DOM)**: Accessible via `curl_cffi` (impersonate `chrome131`). Returns HTTP 200 with ~1.1MB HTML. Can extract title, price, descriptions.
- **Ratings API** (`/api/v4/item/get_ratings` & `/api/v2/item/get_ratings`): **BLOCKED (403 Forbidden)**. Returns `{"error":90309999,"redirect_to_error_page":true}` even when providing valid authentication cookies extracted from a real Chrome Profile 16 session. The backend requires a dynamic client-side token (`af-ac-enc-sz` or `__cf_bm`) generated by Akamai JS.

### 2. Browser Automation (Playwright / Camoufox)
- **Playwright Headless**: Instantly flagged. Redirects to `/verify/traffic/error`.
- **Playwright Headful (Non-headless)**: Flagged. Akamai detects the Chromium DevTools Protocol (CDP) fork and webdriver patterns despite evasions.
- **Camoufox (Firefox-based C++ Patch)**: **Bypasses the WAF** (HTTP 200). Does *not* get redirected to the error page.
- **The Catch with Camoufox**: Shopee Desktop Web lazy-loads reviews. Even when the page loads successfully, the DOM does not contain the `cf.shopee.co.id` image links until the user heavily interacts with the page (scrolling, clicking tabs) to trigger the JS bundle request. In automated contexts, this renders empty.

### 3. Shopee CDN Images (`cf.shopee.co.id`)
- **Direct Search via Search Engines**: 
  - **Google**: Blocked by reCAPTCHA / bot detection for automated scraping.
  - **Bing**: Image URLs are heavily embedded in JSON attributes (`murl`) inside `<a>` tags and are heavily subjected to ISP-level DNS hijacking in Indonesia (forcing SafeSearch Strict), making retrieval unreliable.
  - Shopee CDNs are generally not indexed cleanly for direct keyword searches.

## Final Conclusion
Automated extraction of real user review images directly from Shopee is computationally expensive, highly fragile, and practically blocked by Akamai.

**The Solution:** Use **Pinterest** as the primary image source for real user review photos (querying `"{product} swatches bibir"`, `"{product} di tangan review"`). It has zero WAF, zero rate limiting, and Indonesian users actively upload Shopee review photos there.
