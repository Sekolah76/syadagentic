## RSA DECISION TREE (`rsa_attacks.py`)
- **small e (e=3)** + msg kecil → cube root (`small_e_root`).
- **e=3, msg sama ke 3 penerima** → Hastad broadcast (CRT + cube root).
- **N factorable** → factordb; prime dekat → Fermat (`fermat_factor`); faktor kecil → Pollard.
- **Wiener** → `d` kecil (`wiener`, continued fractions).
- **common modulus** → `n` sama, 2 `e` coprime → Bezout (`common_modulus`).
- **partial key / known high bits** → Coppersmith (Sage `small_roots`).
- **LSB/parity oracle** → binary-search decrypt.
- **p,q/phi diketahui** → `decrypt_with_factors`.
```python
from rsa_attacks import auto, small_e_root, fermat_factor, wiener, common_modulus
m = auto(c, e, n)            # coba attack murah berurutan → plaintext int / None
```

## BLOCK CIPHERS
- **ECB** — block identik → cipher identik; cut-and-paste forge token; byte-at-a-time decrypt vs oracle.
- **CBC bit-flip** — flip byte `C[i]` kontrol `P[i+1]` (auth bypass).
- **CBC padding oracle** — decrypt tanpa key kalau server bocorin pad validity.
- **CTR/stream nonce reuse** — XOR 2 ciphertext → crib-drag.
- **GCM nonce reuse** — forge tag (recover auth key).
