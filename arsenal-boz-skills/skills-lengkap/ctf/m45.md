## ANGR — solver otomatis utama
Dipakai kalau binary validasi input via branching (license/keygen/maze/constraint):
```python
import angr, claripy
p = angr.Project("./chal", auto_load_libs=False)
flag = claripy.BVS("flag", 8*32)
st = p.factory.full_init_state(stdin=flag)
for b in flag.chop(8): st.solver.add(b>=0x20, b<=0x7e)
sm = p.factory.simulation_manager(st)
sm.explore(find=lambda s: b"Correct" in s.posix.dumps(1),
           avoid=lambda s: b"Wrong" in s.posix.dumps(1))
print(sm.found[0].posix.dumps(0))
```
Tips: prefer `find=<addr success print>` drpd string match; `avoid` buat prune; state explosion → `veritesting=True` / hook fungsi mahal. Template: `tools/ctf/templates/angr_solver_template.py` (3 mode: stdin/argv/blank-state).
