⚡ Install (30 detik)

cd syadagentic
bash install.sh              # deteksi otomatis Hermes / Claude Code / Codex / opencode
bash install.sh --dry-run    # lihat rencana, nol tulisan
bash install.sh --no-agent   # salin file saja, config agent tidak disentuh
