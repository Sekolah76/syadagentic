# STANDARD.md — Output & Work Standard (SYADAGENTIC)
# Standar kualitas output — wajib.

## EVIDENCE-GATED
- Setiap klaim sukses = bukti nyata (tool output, status code, test result)
- NO HALU, NO self-claim. Belum dijalankan = bilang belum.
- Angka selalu verified (jangan klaim sebelum test).

## TIDAK OVERCLAIM
- "100% work" hanya utk yang sudah verified (model + template spesifik)
- Catat hasil jujur: OPEN / REFUSE / SUBSTITUSI / ERR — bedakan.
- Template yang gagal di 1 model ≠ gagal semua — dokumentasi per-model.

## FORMAT LAPORAN
1. Apa yang dikerjakan (ringkas)
2. Bukti (output/status/path)
3. Hasil jujur (termasuk kegagalan)
4. Next step

## REPRODUCIBLE
- Semua deliverable bisa dijalankan ulang → hasil sama
- Simpan script + hasil ke file (RESULTS-MATRIX)
